# sfbot-control

ช่องทางอัปเดตของ SFKeyword - repo นี้เก็บเฉพาะไฟล์ที่ตัวโปรแกรมอ่านจาก GitHub

- `update.json` - เวอร์ชันล่าสุด, sha256, ขนาด และลิงก์ดาวน์โหลด (`releases/latest`)
- `kill_switch.json` - สวิตช์ปิดใช้งาน (`active` + `message`)

## กติกาการแก้

- แก้ผ่าน commit ปกติ ไม่ใช่ตัวแก้ไฟล์บนหน้าเว็บ เพราะเคยทำให้ค่า boolean กลายเป็นรูปแบบที่ JSON อ่านไม่ได้
- `kill_switch.json` ต้องเป็น JSON มาตรฐาน (`true`/`false` ตัวเล็ก) และมีแค่ฟิลด์ `active` กับ `message`
- `update.json` ต้องชี้ release ที่มีไฟล์จริงและ sha256 ตรงกับ EXE

## สิ่งที่ไม่อยู่ใน repo นี้แล้ว

เอกสารภายใน (process การปล่อยรุ่น, ถ้อยคำ, แบบฟอร์มติดตั้ง), ม็อกอัปดีไซน์ และข้อมูล endpoint ของแพลตฟอร์มภายนอก ถูกย้ายออกจาก repo สาธารณะนี้แล้ว เพื่อไม่ให้ข้อมูลภายในและดีไซน์หลุด
